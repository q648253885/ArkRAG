## B：设计检查（增量）

| 维度 | 结论 |
|------|------|
| 文本/编码 | ✅ 无乱码（截图验证中文表格、引用来源） |
| 可读性 | ✅ 深浅色正文对比度均 ≥15:1 / ≥7:1；表格次文字 ≥4.5:1 |
| 配色人体工学 | ✅ 近黑近白、accent 小面积、状态色双编码（badge 带文字） |
| 空间密度 | ✅ 桌面 1280px 下卡片留白合理；表格行高 ≥32px |
| 层级 | ✅ 侧边导航选中态 accent 软底；区块标题 14px/600 |
| 热区 | ✅ 按钮 ≥26px（mini）/32px（常规），桌面鼠标场景达标 |
| token 一致性 | ✅ 与插件面板同一变量契约；深色为同 token 暗值 |
| 响应式 | ✅ 1280px 实测；<1024px 折叠导航列 P1 |
