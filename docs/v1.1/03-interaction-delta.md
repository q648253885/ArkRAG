## 2. 布局与信息架构

```
┌────────────────────────────────────────────────────────┐
│ 头部：ArkRAG Console   [token 状态点]  [深/浅色切换]      │
├──────────┬─────────────────────────────────────────────┤
│ 侧边导航  │  内容区（随导航切换）                         │
│ 知识库    │  知识库：KB 表格 + 新建/删除 + 该库文档列表     │
│ 检索试用  │         + 上传（拖拽/选择）+ 摄入状态          │
│ 问答试用  │  检索试用：query + KB 多选 + hits 表           │
│ 模型配置  │  问答试用：query + KB 多选 + 答案 + 引用列表    │
│          │  模型配置：Embedding 组 / Chat 组 表单 + 测试   │
└──────────┴─────────────────────────────────────────────┘
```

首次进入：内容区上浮"访问令牌"输入条（localStorage 记住；401 时自动弹出）。

## 3. 核心流程

**流程 1：首次使用**：打开 /admin → 输入 token（错误时红字"token 无效"）→ 健康检查绿 → 默认落"知识库"。
**流程 2：建库上传问答全链**：知识库 → 新建 → 上传文件（多选）→ 状态行轮询 READY → 问答试用提问 → 答案卡片（引用角标 [1][2]）+ 引用列表（文档名/块/分数）。
**流程 3：在线换模型**：模型配置 → 改 Chat baseUrl/apiKey/model → "测试连通"（分路显示成功/失败原因）→ 保存 → 立即用新模型问答（无需重启）。
**流程 4：换 Embedding 模型**：保存后模型页出现黄条提示"既有知识库需重建索引"；知识库行出现"重建"动作。

## 4. 五态（每个内容区）

| 状态 | 触发 | 表现 |
|------|------|------|
| 默认 | 已登录有数据 | 正常渲染 |
| 加载 | 请求中 | 表格骨架/按钮 loading |
| 空 | 无 KB/无文档/无结果 | 空态文案 + 引导按钮 |
| 错误 | 401/网络失败/业务错误 | 顶部错误条（401 弹 token 输入）+ 重试 |
| 成功 | 操作完成 | toast 2.5s |

## 5. 全局规则

- 反馈/输入/危险操作确认规则与插件面板一致（删除 KB/文档需确认弹窗）。
- 问答试用启用流式关闭（P0 非流式）；超时 120s。
- 响应式：≥1024px 桌面优先；窄屏侧边栏折叠为顶部横滚 Tab（P1）。
