④ 审查清单（请逐项过）

  • ☐ 总览页配色与字号（右上角切换深浅色各看一遍）
  • ☐ 面板原型：五个状态逐个切换（右下角状态切换器），重点看错误态文案是否可行动
  • ☐ 主流程从头点到尾：连接设置 → 测试连接 → 保存 → 新建知识库 → 上传 → 检索
  • ☐ 删除知识库确认弹窗（KB 卡片「⋯」菜单）
  • ☐ token 输入显隐切换、URL 校验红字
  • ☐ 检索结果卡：分数徽标、来源行、长文本展开/收起

注：原型为静态演示，上传/检索/测试连接均为模拟交互；未覆盖的动作会 toast 提示「原型未覆盖此功能」。
